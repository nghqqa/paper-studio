# Elsevier elsarticle 种子来源与许可

- 来源：CTAN `macros/latex/contrib/elsarticle`（腾讯镜像，2026-10 下载）
- 版本：随 CTAN 当前发布；`elsarticle.cls` 由 zip 内 `elsarticle.dtx`+`elsarticle.ins` 经 docstrip（etex）生成
- 许可：LPPL 1.3（可自由再分发）
- 适用：Elsevier 系期刊（Pattern Recognition / Neurocomputing 等）
- 平台适配：骨架为最小可编译示例（preprint 12pt）
