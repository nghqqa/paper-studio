# Word 编辑器与 LaTeX 公式插件

中文论文默认使用原生 DOCX。ONLYOFFICE 负责页面排版、正文编辑和协作，研稿负责项目、权限、文件回传和保存版本。
LaTeX 工程保持原有工作流；历史结构化稿件可创建 Word 副本继续写作。

## 部署

在 `deploy/paper/.env` 中配置：

```dotenv
COMPOSE_PROFILES=word
PATENT_STUDIO_WORD_EDITOR=on
PATENT_STUDIO_ONLYOFFICE_URL=http://你的主机地址:9980
ONLYOFFICE_JWT_SECRET=替换为至少32字符的独立随机密钥
ONLYOFFICE_IMAGE_TAG=10.0.0
```

`ONLYOFFICE_JWT_SECRET` 同时传给研稿和 Document Server，不应与登录会话密钥复用，也不应提交到版本库。
浏览器地址必须能被每位作者访问；使用 HTTPS 的研稿页面也需给 Document Server 配置 HTTPS。
Compose 中应用通过 `http://onlyoffice` 访问编辑器，编辑器通过 `http://app:8000` 获取签名文档。
本机分开运行时，分别设置以下应用环境变量：

| 变量 | 用途 |
| --- | --- |
| `PATENT_STUDIO_ONLYOFFICE_URL` | 作者浏览器访问 Document Server 的地址 |
| `PATENT_STUDIO_ONLYOFFICE_INTERNAL_URL` | 研稿后端访问 Document Server 的地址 |
| `PATENT_STUDIO_ONLYOFFICE_PUBLIC_URL` | Document Server 获取研稿文件和回调的地址 |
| `PATENT_STUDIO_ONLYOFFICE_JWT_SECRET` | 与 Document Server 相同的 JWT 密钥 |

例如 Windows 本机后端端口 8000、Document Server Docker 映射端口 9980：外部和内部地址均为
`http://127.0.0.1:9980`，回调地址为 `http://host.docker.internal:8000`。

在 `deploy/paper` 运行 `./paper.sh up`。ONLYOFFICE 有独立资源预算，默认 4 GB 内存、2 CPU；
首次启动需等 `/healthcheck` 就绪。密钥未配置时，新建窗口会显示服务未就绪，不创建假成功的 Word 项目。

期刊模板指定的字体也需安装到 Document Server；开源回退字体与原模板字体的字宽可能不同。
可将已获使用授权的字体挂载到 `/usr/share/fonts/truetype/custom/`，再在文档服务内运行
`documentserver-generate-allfonts.sh` 并重新打开文档。本项目不附带宋体、黑体或方正等商业字体。

ONLYOFFICE 社区版采用 AGPLv3；按实际固定版本核对源码提供、告知和品牌条款。
插件通过社区版 Plugin API 调用 Office API，不依赖 Developer 版 `createConnector()`。

## 使用

1. 新建项目默认选「Word 论文」，上传 `.docx` 稿件/模板，或选择空白文档、已导入的《中文信息学报投稿模板》。
2. 期刊模板保留完整原件的正文、节、页眉、样式与图片；平台项目名不替换已排版的论文标题。原件实际为旧版 DOC，已转成标准 DOCX，四页渲染对比一致；具体来源与字体条件见 [模板说明](paper-projects-and-templates.md)。
3. 正文空白段落按 `Alt+=` 插入原生公式。在公式末尾输入 `#(2)` 或 `#（2）`，在公式最右端按回车，生成居中公式和右侧手动编号，光标进入下一段正文。
   支持 `(2-1)`、`(2.1a)` 等编号；Shift/Ctrl/Alt+Enter 保留编辑器原有操作。正文中含其他文字的行内公式不会自动改排。
   LaTeX 源码编辑可在「插件」中打开「LaTeX公式」，选择行内/独立方式；面板输入 `E=mc^2#(2)` 也可插入编号公式。
4. 修改已有公式时，刷新「文中公式」清单，选择对应公式、修改 LaTeX，再点「更新原公式」。
   LaTeX 会按编辑器数学模型规范化；首版不承诺双击打开源码，也不处理图片和 MathType/OLE。
5. 「保存」会先等待浏览器同步，再请求 Document Server 回传。收到并持久化 DOCX 后才确认完成。
   保存期间继续改动时，下载会要求再次保存，避免把旧稿当成最新文件。
6. Word 下载保留原生公式；PDF 从已保存 DOCX 版本生成。历史版本只下载，不覆盖当前稿件。

公式面板内有独立滚动条，插入/更新按钮固定在底部；窗口较小时也可滚动到预览和文中公式清单。
表达式错误时，底部会提示检查预览。更新插件后，先复制尚未插入的公式，再关闭并重新打开插件以加载新版。

公式清单采用定位快照保护。选择后若正文/公式已变化，更新会停止，用户输入保留；刷新清单重新选择即可。
自动公式编号、交叉引用和完整 TeX 宏包排版不在首版范围。

### 原生编号与 DOCX 兼容性

编号扩展作为后台插件自动启动，关闭 LaTeX 侧栏不影响正文快捷输入。仅对可编辑角色启动，审阅者和只读用户不自动启动。
原生回车适配固定为 **ONLYOFFICE Docs 10.0.0-169**，在版本与接口不匹配时保留编辑器默认行为。升级文档服务前必须重新验证适配器。
适配器集中在 `backend/app/office_plugin/native.js`，使用 `asc_onBeforeKeyDown` 和该固定构建的少量内部接口完成锁检查、单次撤销事务、公式转换及光标更新；其余文档构造使用公开 Office API。
原生快捷编号现在保留原段落身份，仅替换数学对象并添加制表位和普通编号，不再用新段落覆盖原段落；段落上的书签保持原位。

新编号行使用普通 Word 段落：居中制表位放置原生 OMML 公式，右对齐制表位放置普通编号文本；不创建表格、浮动文本框或图片。
制表位读取当前节的实际栏宽，支持单栏和等宽双栏。插入后的正文段落保留原正文样式，不继承新增的公式制表位。
此方案是 Word 通用的段落排版，并非 Word `#(2)` 所生成的伸展公式阵列。分式、求和等按行内数学样式显示，分式较小、上下限位置也可能与独立公式不同。不用扩大字号或修改公式结构来伪造独立样式。
普通制表位不会自动处理跨行公式的编号；公式换行或编号拥挤时，将光标放在该段落，点击面板「编号另起一行」。该操作只在公式后添加标准换行和制表符，让编号在下一行靠右，不替换公式或段落，不复制批注锚点；支持撤销，重复点击不会添加多余空行。
DOCX 由 ONLYOFFICE 正常保存和下载，导出时不改写 ZIP，不嵌入脚本、宏、私有公式对象或公式图片；离开平台后不需要插件即可显示和继续编辑公式。
普通编号可直接在正文右侧修改；当前编号为手动文本，不会自动递增。原生公式内容仍可通过 LaTeX 清单读取和更新，更新保留编号布局。
通过面板插入独立/编号公式时，读取正文当前光标处的有效字号，连同公式与编号写入 DOCX；不再只复制段落样式后退回文档默认的 11 磅。有效字号不可读时依次检查段落直接格式、段落有效格式、样式和文档默认值，不强制所有模板使用 12 磅。原生键盘编号保留数学对象原有格式，仅让新编号文字匹配当前字号。更新统一字号的公式段落时保留原字号，不随其他位置的光标格式变化；混合字号不统一改写。

自动快捷处理仅覆盖正文独立公式。不等宽分栏、表格内嵌公式、内容控件、节分隔段落、已有修订及开启修订模式等位置保持原始内容，不自动替换。
旧版表格不会因升级自动改写。在 LaTeX 公式面板中，将光标放在旧编号表格内，点击「移除当前公式表格」可转换该表格中的公式行，支持撤销。仅接受每行三格、左格空白、中格一条原生公式、右格为合法编号的无边框固定布局；混有数据、合并单元格或额外内容时保留原表格。
转换会在一次命令中先校验、准备所有行，再替换。文档含批注、修订或书签/交叉引用时拒绝转换，避免 Office JSON 接口未携带的批注锚点和隐藏 `_Ref` 书签丢失；Word 的 `_GoBack` 浏览位置除外。书签完整性检查也固定于上述 10.0.0-169 构建，未知接口拒绝转换。

## 旧结构化稿件

旧稿按原格式保留。先确认旧稿已保存，再点「从已保存稿转为 Word」；系统用原有转换链生成新项目，
标题附「Word 副本」，并保留旧项目。转换依赖应用内 Pandoc 或原有 Docker 导出运行时。
本机运行时需要 Pandoc 3.1 或更高版本，可用 `PATENT_STUDIO_DOCX_PANDOC` 指定其可执行文件。
存在未保存修改、保存冲突或保存任务时，转换按钮会暂停；转换期间暂时锁定旧稿输入。
失效引用、公式门禁或转换器不可用时会明确失败，不覆盖旧稿。

## 数据与保存边界

- `document.docx` 是 Word 项目正式内容，不经过 Markdown/HTML 中转。
- `.studio/word/versions/` 保存按内容 SHA 区分的快照；元数据在 `.studio/word/state.json`。
- 同一文档共编会话共享 key；最终保存后换 key，旧会话回调不能覆盖新会话。
- 编辑配置、文件下载能力和回调分别签名；回调下载只接受配置的 Document Server 缓存地址。
- 研稿普通 API 使用原有项目 ACL；Document Server 获取文件使用用途绑定的签名凭据。
- 本机断网、服务异常或保存超时时，不把“已受理”显示为“已保存”；请保留编辑器页面并重试。
